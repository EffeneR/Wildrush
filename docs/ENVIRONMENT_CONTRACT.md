# Environment Art Contract (Briarport)

The canonical gameplay layout is `game/data/arena/briarport_layout.json`, generated by
`tools/arena/gen_layout.py` (owned by the lead). The game builds **all collision,
occupancy volumes, spawn barriers, perch ledges and navigation** from that JSON. The
environment art pipeline builds the **visual** arena from the same JSON so that what
players see matches what they collide with.

## Outputs
| Path | Content |
|------|---------|
| `blender/arena/*.py` | generation scripts (executed, reproducible via `tools/build_arena_art.sh`) |
| `blender/arena/briarport.blend` | editable source scene (kit collection + assembled arena) |
| `blender/arena/kit/*.blend` (optional) | kit source pieces |
| `game/assets/arena/textures/*.png` | tileable PBR textures (1K–2K): albedo, normal, roughness(+AO) |
| `game/assets/arena/briarport_<chunk>.glb` | visual chunks: `A`, `B`, `C`, `north`, `south`, `skyline` (+ `props` if useful) |
| `game/assets/arena/arena_art.json` | manifest: chunks, special-mesh list, triangle counts, material list |
| `evidence/arena/blender_overview.png`, `evidence/arena/blender_<district>.png` | Blender renders for review |

## Geometry rules
* Units metres, Blender Z up ↔ Godot Y up; layout JSON is Godot space (X east, Y up,
  Z south). Mapping to Blender: `bx = x, by = -z, bz = y` (glTF export converts back).
  Verify with a test object that a layout point lands at the same Godot coordinate.
* Walkable surfaces: visual top within ±0.03 m of the floor/ramp tops in the JSON.
  Stairs (`kind: stairs`) are visual steps whose nosings follow the ramp line.
* Solids: visual walls within ±0.15 m of the box faces up to 2.5 m height. Buildings
  (`kind: building`, `style` hint) are 8–16 m facades with windows, doors, balconies,
  cornices, terracotta roofs; details above 2.5 m may overhang ≤ 1 m. Nothing may hang
  below 2.4 m over any walkable floor except inside solid footprints.
* `collide: false` solids (balustrades) are visual only (blockers are invisible
  colliders in the JSON — draw balustrades/quay walls along them).
* Water (`water` list): surface quad(s) at the given `y`, named `water_*`; canal walls
  from y=−3 up to the adjoining floor level; boats (`decor: boat`) float at water level.
* Decor entries (`decor` list): place matching props (lamp posts, banners on posts and
  walls, barrels, pallets, forklift, crane, boats, chimney smoke emitter placeholders
  `emit_smoke_*` empties, skyline buildings/towers outside the footprint, puddles).
  Decor never adds collision.
* Zones: do not bake zone rings into the art (the game draws state-dependent rings).
  Keep the 9 m scoring circles free of tall clutter.

## Look (references 7–11, spec §7)
Waterfront brick-and-stone district, warm clear daylight, restrained ivy, banners
(crimson cloth with an original three-claw emblem; slogans are optional set dressing),
terracotta roofs, market stalls with red/green canopies, planters with small trees,
central fountain with a modest statue, lamp posts, stone balustrades, arched bridges
(walkable deck flat at the JSON height), boats outside the fighting surface, shallow
puddles (flat meshes named `puddle_*` at y+0.005 with their own material), industrial
loading yard: concrete/steel platform, hazard striping, crate stacks with tarps,
shipping containers, drain grates, overhead jib crane outside collision routes.

## Special mesh names (Godot replaces or post-processes these)
`water_*` (water shader), `puddle_*` (wet decal material), `foliage_*` (alpha-clip, two-sided),
`emissive_*` (lamp glass), `banner_*` (cloth, two-sided), `emit_smoke_*` (empties).

## Budgets
Whole arena ≤ 1.2 M triangles before LOD; props instanced (linked duplicates →
shared glTF meshes); ≤ 40 materials total; textures 1K–2K, tileable; chunked per district.
