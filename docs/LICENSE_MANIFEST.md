# License manifest

Everything shipped in or used to build WILDRUSH, with its licence. "Shipped" = inside the
exported game client or dedicated server. "Service" = the self-hosted control service
(not part of the game client). "Tool" = used only to produce or verify assets/builds.

## Original work (this project)
| Item | Location | Notes |
|---|---|---|
| Game code (GDScript), scenes, shaders, tuning data | `game/` | original |
| Characters (meshes, rigs, textures, 49-clip animation sets) | `blender/characters/`, `game/assets/characters/` | generated by the project's own Blender scripts; original |
| Briarport arena art, textures | `blender/arena/`, `game/assets/arena/` | generated by the project's own Blender/Python scripts; original |
| Sound effects, ambience, music | `tools/audio/`, `game/assets/audio/` | synthesised procedurally (numpy/scipy); no third-party samples, no voice impersonation |
| UI art, icons, wordmark | `game/src/ui/`, `game/assets/ui/` | drawn in code / original |
| Control service, allocator, deployment config | `services/` | original |
| Reference images | `references/` (git-ignored) | owner-supplied, used for design reference only, **not distributed** |
